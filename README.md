# Full Page Downloader (دانلود کامل صفحه به صورت ZIP)

اکستنشن کروم برای دانلود کامل هر صفحه وب (HTML + CSS + JS + تصاویر + فونت‌ها) به‌صورت یک فایل ZIP، بدون نیاز به هیچ ابزار خارجی.

## نصب (حالت Developer)

1. آدرس `chrome://extensions` را در کروم باز کن.
2. گزینه‌ی **Developer mode** را در گوشه‌ی بالا-راست فعال کن.
3. روی **Load unpacked** بزن و پوشه‌ی این پروژه (`page-downloader-extension`) را انتخاب کن.
4. آیکون اکستنشن روی نوار ابزار کروم ظاهر می‌شود.

## استفاده

هر صفحه‌ای که باز داشتی (باید `http` یا `https` باشد)، روی آیکون اکستنشن کلیک کن.
چند ثانیه صبر کن (بسته به حجم صفحه)، پنجره‌ی ذخیره‌ی فایل باز می‌شود و یک فایل `.zip` شامل:

```
index.html
assets/css/...
assets/js/...
assets/img/...
assets/fonts/...
assets/misc/...
```

دریافت می‌کنی. فایل `index.html` را باز کن — همه‌چیز آفلاین و لوکال کار می‌کند.

## نحوه‌ی کار

1. با کلیک روی آیکون، یک تابع داخل خود صفحه اجرا می‌شود و HTML کامل صفحه + آدرس همه‌ی منابع (عکس‌ها، لینک‌های CSS، اسکریپت‌ها، آیکون‌ها، بک‌گراندهای اینلاین) را جمع‌آوری می‌کند.
2. سرویس‌ورکر اکستنشن (`background.js`) هر منبع را دانلود می‌کند؛ اگر منبع یک فایل CSS باشد، متنش را هم برای `url(...)` و `@import` (فونت‌ها، بک‌گراندها) اسکن می‌کند و آن‌ها را هم به صف دانلود اضافه می‌کند.
3. تمام آدرس‌ها در متن HTML و CSS با مسیرهای لوکال جایگزین می‌شوند.
4. با کتابخانه‌ی [JSZip](https://stuk.github.io/jszip/) (که داخل پوشه‌ی `libs/` قرار داده شده) همه‌چیز در یک فایل ZIP بسته‌بندی و دانلود می‌شود.

## محدودیت‌ها (مهم)

- **بک‌گراندهای تعریف‌شده در استایل‌شیت‌های خارجی**، شناسایی و دانلود می‌شوند؛ اما بک‌گراندهایی که با جاوااسکریپت به‌صورت داینامیک به DOM اضافه می‌شوند (مثلاً بعد از اسکرول یا با CSS-in-JS runtime) ممکن است در لحظه‌ی کلیک هنوز رندر نشده باشند.
- منابعی که سرور اجازه‌ی CORS برایشان نداده باشد ممکن است دانلود نشوند؛ در این صورت لینک اصلی (آنلاین) در HTML خروجی باقی می‌ماند، ولی کل صفحه از کار نمی‌افتد.
- محتوای پشت `iframe` از دامنه‌ی دیگر (cross-origin) دانلود نمی‌شود — فقط تگ `iframe` با `src` اصلی باقی می‌ماند.
- صفحاتی که با JavaScript به‌صورت کامل رندر می‌شوند (SPA) دقیقاً در همان وضعیتی که هنگام کلیک روی صفحه بودند (DOM فعلی) ذخیره می‌شوند — نه سورس اولیه.
- فایل‌های خیلی بزرگ (ویدیوهای حجیم و…) ممکن است زمان‌بر باشند یا با محدودیت حافظه‌ی سرویس‌ورکر مواجه شوند.

## توسعه‌های پیشنهادی بعدی

- افزودن progress bar در یک popup برای نمایش وضعیت دانلود.
- پشتیبانی از دانلود `iframe`های هم‌دامنه.
- گزینه‌ی انتخاب "فقط HTML+CSS" یا "همه‌چیز شامل ویدیو" برای کنترل حجم خروجی.
