# Full Page Downloader (دانلود کامل صفحه به صورت ZIP)

اکستنشن کروم برای دانلود کامل هر صفحه وب (HTML + CSS + JS + تصاویر + فونت‌ها) به‌صورت یک فایل ZIP، بدون نیاز به هیچ ابزار خارجی.

## نسخه 4.0.0

این نسخه شامل ویژگی‌های پیشرفته زیر است:
- **خزش چند صفحه‌ای (Crawling)** با کنترل عمق و تعداد صفحات
- **پاپ‌آپ تنظیمات** برای کنترل کامل دانلود
- **سیستم پیشرفت‌گیری** برای نمایش وضعیت واقع‌زمان
- **دانلود موازی** برای سرعت بیشتر
- **فیلترینگ هوشمند** منابع بر اساس نوع و دامنه

## نصب (حالت Developer)

1. آدرس `chrome://extensions` را در کروم باز کن.
2. گزینه‌ی **Developer mode** را در گوشه‌ی بالا-راست فعال کن.
3. روی **Load unpacked** بزن و پوشه‌ی این پروژه را انتخاب کن.
4. آیکون اکستنشن روی نوار ابزار کروم ظاهر می‌شود.

## استفاده

### دانلود تک صفحه
1. روی آیکون اکستنشن کلیک کن.
2. تنظیمات را بر اساس نیازت انتخاب کن.
3. روی "دانلود صفحه" کلیک کن.
4. فایل ZIP دانلود می‌شود که شامل HTML کامل و تمام منابع است.

### خزش چند صفحه‌ای (Crawling)
1. در پاپ‌آپ، گزینه "فعال‌سازی خزش صفحات" را فعال کن.
2. عمق خزش (1-5 لایه) را تعیین کن.
3. حداکثر تعداد صفحات (1-100) را تنظیم کن.
4. فیلترهای دامنه و لینک‌های داخلی را انتخاب کن.
5. روی "دانلود صفحه" کلیک کن.

## تنظیمات

### تنظیمات منابع
- **دانلود تصاویر**: شامل PNG، JPG، GIF، SVG، WebP و...
- **دانلود ویدیوها**: شامل MP4، WebM، OGG و...
- **دانلود فایل‌های صوتی**: شامل MP3، WAV، FLAC و...
- **دانلود فونت‌ها**: شامل WOFF، WOFF2، TTF و...
- **حداکثر حجم فایل**: بین 1 تا 500 مگابایت

### تنظیمات خزش
- **فعال‌سازی خزش صفحات**: برای دانلود چند صفحه به‌صورت خودکار
- **عمق خزش**: تعداد لایه‌های لینک‌دن (1-5)
- **حداکثر صفحات**: محدودیت تعداد صفحات دانلود شده (1-100)
- **فقط لینک‌های داخلی**: فقط لینک‌های همان صفحه را دنبال کن
- **فقط همان دامنه**: فقط لینک‌های همان دامنه را دانلود کن

## نحوه‌ی کار

1. با کلیک روی آیکون، یک تابع داخل خود صفحه اجرا می‌شود و HTML کامل صفحه + آدرس همه‌ی منابع را جمع‌آوری می‌کند.
2. سرویس‌ورکر اکستنشن هر منبع را دانلود می‌کند؛ اگر منبع یک فایل CSS باشد، متنش را هم برای `url(...)` و `@import` (فونت‌ها، بک‌گراندها) اسکن می‌کند.
3. تمام آدرس‌ها در متن HTML و CSS با مسیرهای لوکال جایگزین می‌شوند.
4. با کتابخانه‌ی [JSZip](https://stuk.github.io/jszip/) همه‌چیز در یک فایل ZIP بسته‌بندی می‌شود.
5. در حالت خزش، لینک‌ها استخراج شده و صفحات اضافی دانلود می‌شوند.

## ویژگی‌های جدید نسخه 4.0.0

### خزش هوشمند
- کنترل عمق خزش برای جلوگیری از حلقه‌های بی‌نهایت
- فیلترینگ لینک‌ها بر اساس دامنه و نوع
- مدیریت خودکار تب‌ها برای خزش صفحات
- جلوگیری از بازدید دوباره صفحات

### رابط کاربری پیشرفته
- پاپ‌آپ فارسی با RTL
- تنظیمات کامل و قابل شخصی‌سازی
- اعتبارسنجی ورودی‌ها
- ذخیره تنظیمات برای استفاده بعدی

### سیستم پیشرفت‌گیری
- نمایش درصد پیشرفت در badge
- پیام‌های وضعیت در پاپ‌آپ
- نوتیفیکیشن خطا
- گزارش منابع نادیده گرفته شده

### پشتیبانی گسترده منابع
- پشتیبانی از SVG و Canvas
- پشتیبانی از @font-face و mask-image
- پشتیبانی از Open Graph و Twitter Card
- پشتیبانی از picture element و srcset
- پشتیبانی از inline styles و scripts

## محدودیت‌ها

- منابعی که سرور اجازه‌ی CORS برایشان نداده باشد ممکن است دانلود نشوند.
- محتوای پشت `iframe` از دامنه‌ی دیگر (cross-origin) دانلود نمی‌شود.
- صفحاتی که با JavaScript به‌صورت کامل رندر می‌شوند (SPA) دقیقاً در همان وضعیتی که هنگام کلیک بودند ذخیره می‌شوند.
- فایل‌های خیلی بزرگ (ویدیوهای حجیم) ممکن است زمان‌بر باشند.

## نحوه باز کردن فایل ZIP

برای باز کردن این صفحات با کمترین مشکل، پیشنهاد می‌شود به‌جای دابل-کلیک مستقیم، یک سرور محلی اجرا کنید:

### با پایتون
```bash
python -m http.server 8000
```
سپس در مرورگر بروید به: `http://localhost:8000`

### با فایل serve.py داخلی
فایل `serve.py` داخل پوشه ZIP را دابل-کلیک کنید (در صورت نصب بودن پایتون).

### برای خزش چند صفحه‌ای
برای مشاهده فهرست صفحات: `http://localhost:8000/pages/index.html`
